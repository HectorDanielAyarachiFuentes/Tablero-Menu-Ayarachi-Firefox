# Reglas para Generación de Mensajes de Commit (Git)

Cualquier mensaje de confirmación (commit) generado para este repositorio debe seguir estrictamente estas pautas:

1. **Idioma:** Redactar SIEMPRE el título y descripción del commit en **español**.
2. **Formato Conventional Commits:**
   - `feat: <descripción>` para nuevas funcionalidades, widgets, temas o componentes.
   - `fix: <descripción>` para correcciones de bugs, errores de renderizado o fallos de almacenamiento.
   - `docs: <descripción>` para cambios en documentación, guías o manifiestos.
   - `refactor: <descripción>` para reorganización de código, modularización o mejoras estructurales sin alterar funcionalidad.
   - `perf: <descripción>` para optimizaciones de carga (Layered Loading, Zero-Flash, IndexedDB, etc.).
   - `test: <descripción>` para pruebas de integración o scripts de validación.
   - `chore: <descripción>` para configuración del repositorio, dependencias o tareas de mantenimiento.
3. **Estilo:**
   - Iniciar en minúscula tras el prefijo.
   - Ser conciso, claro y no incluir punto final al término del título.
